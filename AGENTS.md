# Continuidade do projeto Arkai

- Antes de trabalhar neste repositório, leia `docs/CONTINUIDADE.md` e confira `git status` e os arquivos citados no assunto atual.
- Ao começar um novo assunto, registre no documento o pedido e o estado inicial. Ao concluir, atualize o resultado, as verificações, o que ficou pendente e o commit/deploy, se houver.
- Publique a atualização no GitHub para que outro agente possa retomar, conforme a autorização contínua do usuário para este documento. Inclua no commit somente arquivos pertinentes ao assunto; preserve mudanças locais não relacionadas.
- Não copie a transcrição integral da conversa, dados pessoais, credenciais, tokens ou payloads reais de leads. Distinga fatos verificados, informações relatadas pelo usuário e hipóteses.
- Se a publicação falhar ou precisar de uma decisão do usuário, deixe isso explícito no documento e na resposta; não afirme que o GitHub está atualizado sem verificar o push.
